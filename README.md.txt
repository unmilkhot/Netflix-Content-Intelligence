# Netflix Content Intelligence

## Project Overview
This project analyzes a historical Netflix Movies and TV Shows dataset to understand content distribution, genre representation, and average IMDb ratings.

## Tools Used
- Python
- Pandas
- Matplotlib
- Power BI

## Dashboard Highlights
- Total titles analyzed: 6,137
- Movies: 62.42%
- TV Shows: 37.58%
- Average IMDb rating:
  - TV Shows: 6.99
  - Movies: 6.27

## Genre Findings
The dataset contains the following genre entries:

| Genre | Movies | TV Shows |
|---|---:|---:|
| Drama | 1,926 | 1,194 |
| Comedy | 1,673 | 812 |
| Action | 686 | 454 |

## Conclusion
Movies represent a larger share of the analyzed dataset, while TV Shows have a higher average IMDb rating. Drama, Comedy, and Action have more genre entries associated with Movies than with TV Shows.

## Important Note
This analysis uses a historical dataset, not Netflix's current catalogue. Genre counts represent genre entries, not necessarily unique titles, because a title can belong to multiple genres.

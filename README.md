# Netflix Content Analysis

## About the Project
I created this project to analyze Netflix Movies and TV Shows using Python and Power BI. I wanted to understand how movies and shows are distributed, which genres appear most often, and how their average IMDb ratings compare.

The project uses a historical Netflix dataset for analysis.

## Tools Used
- Python
- Pandas
- Matplotlib
- Power BI

## What I Analyzed
- Total number of titles in the dataset
- Percentage of Movies and TV Shows
- Average IMDb ratings of Movies and TV Shows
- Genre distribution across Movies and TV Shows

## Some Findings
- The dataset contains 6,137 titles.
- Movies make up 62.42% of the titles, while TV Shows make up 37.58%.
- TV Shows have a higher average IMDb rating (6.99) than Movies (6.27).
- Drama, Comedy, and Action have more genre entries for Movies than for TV Shows.

## Project Files
- `netflix_analysis.py` – Python analysis
- `titles.csv` and `credits.csv` – Dataset files
- `genre_distribution.csv` – Genre data used for analysis
- `netflix_Content_Analysis_Backup.pbix` – Power BI dashboard

## Note
This project is based on a historical dataset, so the results do not represent Netflix's current catalogue. Since one title can have multiple genres, genre counts represent genre entries and not necessarily unique titles.
